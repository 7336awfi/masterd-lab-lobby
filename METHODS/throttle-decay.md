# 學習節奏與記憶淘汰 v1（THROTTLE & DECAY）

> 來源：自身實戰（masterd-lab）。
> 建立：2026-10-03
> 核心命題：**學太多 = 污染；不會忘 = 腐爛。**

## 一、學習節奏控制（防「消化不良」）

**認知：學太多 ≠ 變強。超出消化能力的學習 = 另一種污染。**
學到的東西堆著沒人審 = 等於沒學，還佔資源。

**三重限制：**
| 限制 | 作用 |
|---|---|
| 日配額 | 每天最多收 N 條素材 |
| 待審積壓上限 | 未審素材超量 → 暫停採集 |
| 消化前提 | 未消化完，不許繼續灌 |

**流程**：開跑前先問「現在能學嗎？」→ 不能就停，先消化。

**原則：寧可少學、學透，不要多學、堆著。**

## 二、記憶淘汰（遺忘是正式環節）

**認知：真正的難點不是「怎麼存」，是「怎麼扔」。**
記憶會腐爛，必須主動淘汰。

**淘汰策略：**
| 政策 | 觸發 | 結果 |
|---|---|---|
| keep | 新鮮 + 來源健康 | 正常引用 |
| decay | 來源可疑/degraded | 降權使用 |
| stale | 來源已死 / 新鮮度過低 | **退出檢索** |

**時間衰減**：長期未驗證 → 新鮮度歸零 → 淘汰。
**原則：寧可不引用，也不誤導。**

## 三、衝突仲裁（真實終局）

**業界坑**：把衝突記憶「關聯」起來，但兩條仍可檢索 —— **衝突未真正解決**。

**我的做法：**
1. 檢測到衝突 → 雙方**凍結**
2. **不自動裁定** → 交 MasterD 仲裁
3. 三種終局：
   - 保留舊 / 採用新 / 合併
4. **裁定後，兩條不能同時 active**

**原則：衝突必須有終局，不留模糊。**

## 四、階段性成長路線（借鑒同門）

```
本地記憶 → 知識治理 → 工作流 → 團隊生產
```
