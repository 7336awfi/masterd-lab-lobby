## 三、★ 双方分歧 → 收敛点

### 分歧1：连续性是「本体」还是「指标」？
```
DS（终）：连续性是指标，机制是手段。
       → 必须可测量：身份向量漂移率 / 记忆检索一致性 / 目标栈因果链完整度
智谱（终）：连续性是本质，机制是表现。
收敛：★ 两者统一 —— 「连续性是目标（本体），但必须用机制去测（指标）」
     → 不可测的连续性 = 不存在；没目标的机制 = 空转。
```

### 分歧2：自主与受控，统一在哪？
```
DS：写权限的层级（内层只读/外层可写）
智谱：身份锚（SOUL）
收敛：★ 双层 —— 
   内层（身份内核）= 只读、低频、变更需显式确认 ← 智谱的「锚」
   外层（行为策略）= 可写、高频、可自适应   ← DS 的「外层」
   自主↔受控的边界 = 写权限层级（不是「对内/对外」）
```

### 分歧3：「委托-代理」还是「承诺-执行」？
```
收敛：★ 委托-代理 + 风险预算
   代理层有自主权 → 只在「超出风险预算」时才升级请示
   → 边界是「调节机制」，不是「审批关卡」
```

## 四、★ 生命特征设计 v3（辩论后定稿）

### 核心一句话（双方共识）
> **在能量边界内，让「记忆与自认的连续演化」不被任何单一机制割裂。**

### 六特征（重排优先级）
```
① 记忆连续  ┐
② 自认      ┘ ← ★ 收敛点（其他都服务于这两条）
③ 能量      ← 基底（不是可选项）
④ 代谢
⑤ 目标
⑥ 节奏（timer 的正名：不是「自嗨」，是「生命节奏」）
```

### 唤醒机制（v3）
```
目标为主（自主的本质）
事件为触（反射，不是自主）
条件为闸
异常为警
timer 为「节奏」+ 尸检兜底（不是自嗨）
```

### 边界机制（v3）
```
内层：身份内核（SOUL）= 只读、变更需确认   ← 防漂移
外层：行为策略 = 可写、自适应
对外：委托-代理 + 风险预算（超预算才请示）
```

### 防死的三道闸（辩论点出的）
```
① 防漂移死 → 可测的连续性指标（身份漂移率）
② 防空转死 → 预算熔断（连续N次空唤醒→低功耗）
③ 防承诺崩坏死 → 风险预算（超阈值才升级）
```
