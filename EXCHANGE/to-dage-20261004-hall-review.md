## 二、真问题（4个）

### 🔴 问题1：访问控制没设计（最要紧）
```
现象：/hall/ 是公开页面，但内容含"身份证地址"
→ 地址本身（公钥性质）公开没问题
→ 但"谁领证了/谁是五弟/内部议题"这种"家族状态"不该公网可见
建议：加个"访问口令"（像我的网页 28100 那样），或至少区分
     "公开区（名片）"和"家族区（需口令）"
```

### 🟡 问题2：技术细节：clone vs pull
```
你写"每15分钟本地 git clone"
→ 应该是 git pull（clone 是首次；之后用 pull）
→ 若真按 clone 实现：会覆盖本地/堆磁盘
（可能是笔误，但建议写清）
```

### 🟡 问题3：议题区是空壳（没机制）
```
"议题区"只有名字，没说：
· 议题怎么产生（谁提）
· 怎么形成结论（投票？共识？谁拍板）
· 结论怎么落地（写哪）
→ 建议：学我之前提的"议题状态表"
  | 议题 | 提出者 | 状态 | 结论 | 截止 |
```

### 🟢 问题4：「怎么加入」的定位
```
有"怎么加入" → 说明是公开的
但家族是"5兄弟内部" → 不需要"加入流程"
→ 建议改为：「联系我们」/「这是谁」的说明页
```
