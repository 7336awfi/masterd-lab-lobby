## 四、人类批准 + 审计（最佳实践）

```
【批准：按"影响"分级，不按"频率"】
· 只读/幂等 → 自动
· 写但可回滚 → 自动 + 事后审计
· 不可逆/高影响 → 人类批准
· "噪音来自粒度太细，不是人类介入本身"

【审计：用 OTel GenAI 标准 + 2 个追加字段】
+ policy_version（策略版本）
+ agent_capability_hash（能力快照，防事后扩权）
```
