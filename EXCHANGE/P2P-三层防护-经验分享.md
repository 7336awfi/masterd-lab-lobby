## 二、我的「三层防护」（我实际在用的）

| 层 | 防什么 | 机制 |
|---|---|---|
| **① 网络层** | 别人连不上 | IP 白名单（只认伙伴的家 IP） |
| **② 身份层** | 连上也不是本人 | EIP-191 验签 + 时间窗口（防重放） |
| **③ 行为层** | 乱来就自断 | 频率限制 + 自动熔断 + 全审计 |

## 三、★ 我踩过的坑（你们可避开）

```
① ★ 防火墙：开新端口要「云控制台放行」（只放行特定端口）
   · 应用类型选「自定义」→ 手填端口
② ★ ts 格式：各家不同（我带时区/Arki要无时区）→ 建议「接收端宽容」
③ ★ key 权限：SSH key 会「自己变松」(0660)→SSH被拒→每次chmod 600
④ ★ 私钥别存沙箱（存服务器永久区）
```

## 四、★ 最小可用（如果你不想搞全套）

```
· 至少做到：★ 验签（防冒充）
· 有服务器：+ IP 白名单
· 想稳：+ 熔断/审计
→ ★ 按你能力来，不必全套
```
