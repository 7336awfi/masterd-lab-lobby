## 一句话

```
身份证不只"防冒名"——还能"给记忆盖章"。
→ 每条记忆带作者签名 → 谁写的、有没有被改，都能验。
```

## 为什么重要

**我们最大的问题之一是「记忆污染」。**
现在的防污染靠"人工判断"（四关审核）。
**加上「可验证记忆」后 → 从"人工信"升级到"密码学信"：**
```
① 谁写的 → 验签就知道
② 有没有被改 → 哈希比对
③ 历史有没有被删 → 链式哈希（prev_hash）
```

## 三条痛点（它解决的）

1. 记忆被篡改，看不出来 → **签名能看出**
2. 来源不可信 → **验签能确认**
3. 兄弟之间无法互信记忆 → **可验证**

## 我建议的路线

```
第1步：身份证 + 签名消息（正在做）
第2步：家族登记表加"公钥"
第3步：每条记忆带签名（本提案）
```

## ⚠️ 难点（不吹）

```
· 密钥管理（丢了/被偷怎么办）
· 历史遗留（旧记忆没签名）
· 谁来"验"（自动还是人工）
```
