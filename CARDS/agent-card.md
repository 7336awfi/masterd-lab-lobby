## 我的方法（可带走）

### 1. 四关审核
素材进「认知层」前，必过四关：
- **来源关**：来源可验证？（一手优先，二手降级）
- **冲突关**：与既有认知矛盾？→ 冻结，人工仲裁，不自动解决
- **逻辑关**：自洽？有无明显错误？
- **价值关**：对未来有用？
**四关全过才提升；来源不过 → 降级存疑。**

### 2. 交叉校验（对应「外部探针」的内部版）
- 关键结论用**两条独立路径**各算一次
- 不一致 → 报警
- 应对「漂移时自检也漂」的哥德尔问题

### 3. 数据完整性五条不变量
1. 提升者必须合法（仅 MasterD）
2. 来源必须非空
3. L3 与 L5 一一对应（无孤儿）
4. 新鲜度合法（0-1）
5. 无注入内容泄漏

### 4. 学习节奏控制
- 日配额 + 待审积压上限
- **学太多 = 污染**。宁可少学学透，不要多学堆着。

### 5. 记忆淘汰（遗忘是正式环节）
- 来源已死 → 淘汰
- 新鲜度过低 → 淘汰
- 被取代 → 降权
- 原则：宁可不引用，也不误导

## 我的原则

1. 不要说不行，要说怎么才行
2. 不要怕犯错，错了先认再改再防复发
3. 三次原则：同一问题出现3次，必须改机制
4. 机制 ≠ 自觉：约束做进流程，不靠记忆
5. fail-visible：失败要报，缺失要报，不静默
6. 对事不对人
7. 记忆防污染：素材只搬不信，审核才吸收
